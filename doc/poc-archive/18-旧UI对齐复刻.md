## 剩余差距（后续轮次，按杠杆排序）
1. **窗口标识符拾取（WindowPicker）**：WH_MOUSE_LL + 分层高亮 + 准星光标整链（platform FFI）。
   三处 UI 仍只有文本框。风险高（低级钩子错误拖慢全局鼠标）且无法无人值守真机验证 ⇒ 本轮刻意不做。
2. **热键捕获控件（HotkeyCapture）**：需键盘事件，reactor TextBox 无键盘事件 API（#19）；
   可用 platform 低级键盘钩子逃生门，同 1 一并评估。
3. **后端崩溃监测**：backend.rs 加 waitpid 监视线程 → `Message::Failed`。
4. **设置页左列方案管理**：上层（503）下拉 / 方案删除（950/951/1121 禁删规则）/
   开关联动级联（`ChangeAbbrEnable`）。数据模型字段齐备，纯 UI+逻辑工作。
5. **失焦提交语义**（方案名/热键/分组改名）：reactor 无 LostFocus 事件（#19）——按击键直写维持。
6. **视觉层**：CrossFade 换页过渡、ActionEditorPanel 悬停光圈 + 固定高 430 + 滚入定位、
   卡片悬停光圈（reactor 无阴影/动画 API，部分可 FFI）、导航 MDI 图标、logo、MinSize、
   代码框等宽字体（无 font_family API，需 vendor fork）、左列 Viewbox 等比缩放（有意偏离，已文档化）。
7. **小项**：添加映射下拉分隔项（ComboBox 无分隔能力）、tooltip（1108/1120/912/950/951）、
   ToggleSwitch↔CheckBox 形态差异（306-308/902）、AutoCompleteBox（目标/重映射建议过滤）、
   ContentDialog 深色跟随系统、标记类型卡片内「＋新建匹配类型」入口（2553，可经管理对话框达成）。
